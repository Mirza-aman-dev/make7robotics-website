# Make7 Robotics - Official Website

Welcome to the official repository for the Make7 Robotics company website. 
Make7 Robotics is transforming the educational landscape in Qatar by bringing accessible, practical robotics, coding, AI, and technology learning directly into schools.

## Features
- **Modern UI/UX**: Designed with sleek glassmorphism, responsive components, and stunning visual effects.
- **Scroll Animations**: Butter-smooth GSAP-powered scrolling and text-highlight animations.
- **Interactive 3D Elements**: Uses React Three Fiber and Three.js for an engaging, interactive robot mascot.
- **Responsive Navigation**: Includes a custom desktop overlay and a glass-paneled mobile menu.
- **Tailwind CSS integration**: Uses modern, rapid styling built on Tailwind framework.

## Tech Stack
- **Framework**: React 18
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: GSAP, Framer Motion
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Icons**: Lucide React

## Development
To run this project locally:

1. **Install dependencies**
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Start the development server**
   ```bash
   npm start
   ```

3. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Deployment
This project is configured and linked to be deployed via Netlify (`make7robotics.com`).
